# Jeev Joel — Portfolio

A responsive, interactive portfolio website built with **HTML, CSS, and vanilla JavaScript**.

## Run locally
No build step or package installation is required.

1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local development server, run:
```bash
python -m http.server 5500
```
Then visit `http://localhost:5500`.

## Interactions
- Responsive navigation and mobile menu
- Light/dark theme toggle (saved in local storage)
- Scroll reveal animations and reading progress bar
- Project category filters
- Project detail modal windows
- Copy email button
- Quick navigation command palette (`Ctrl + K` / `⌘ + K`)
- Reduced-motion accessibility support

## Customise
- Update content and project cards in `index.html`.
- Update project modal copy in `script.js` (`projectData`).
- Update colours, typography, and layout in `style.css`.
- Add real project demo/repository links when available.

## External assets
Google Fonts and Lucide icons are loaded from CDNs. The website itself has no framework or build dependency.
